# P01 Lucene Tokenization

## Requirements

- Java 21
- Maven

## Run

```text
mvn compile exec:java
```

## Folder structure

```text
src/main/java/
  P01.java
  input/TextInput.java
  tokenizer/TokenizerTasks.java
  output/TokenPrinter.java
README.md
```

The output lists the tokens produced by the standard, whitespace, stop-filter, and custom analyzer pipelines.
